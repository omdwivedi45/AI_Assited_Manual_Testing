# BUG-001: SYSTEM ALLOWS PURCHASE FLOW WITH A COMPLETELY EMPTY CART

- **SEVERITY:** HIGH
- **PRIORITY:** HIGH
- **MODULE:** CART_CHECKOUT
- **ENVIRONMENT:** STAGING / PRODUCTION (SAUCEDEMO.COM)

## PRECONDITIONS:
1. USER IS LOGGED IN SUCCESSFULLY WITH STANDARD_USER CREDENTIALS.
2. THE SHOPPING CART IS COMPLETELY EMPTY (COUNT IS 0).

## STEPS TO REPRODUCE:
1. NAVIGATE TO THE SHOPPING CART VIEW.
2. CLICK ON THE 'CHECKOUT' BUTTON WITHOUT ADDING ANY PRODUCT.
3. OBSERVE THE SYSTEM BEHAVIOR AND PURCHASE FLOW ACTION.

## EXPECTED RESULT:
THE SYSTEM SHOULD RESTRICT THE CHECKOUT PROCESS, DISPLAY A VALIDATION ERROR MESSAGE, AND PREVENT THE USER FROM PROCEEDING TO THE SHIPPING INFO PAGE WITH AN EMPTY CART.

## ACTUAL RESULT:
THE SYSTEM BYPASSED VALIDATION AND ALLOWED A MEANINGFUL PURCHASE FLOW ALTHOUGH THERE WAS NO ITEM IN THE USER CART.
