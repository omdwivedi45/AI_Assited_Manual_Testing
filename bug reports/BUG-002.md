# BUG-002: CHECKOUT PAGE ACCEPTS INVALID SPECIAL CHARACTERS IN NAME FIELDS

- **SEVERITY:** MEDIUM
- **PRIORITY:** HIGH
- **MODULE:** CHECKOUT_INFORMATION
- **ENVIRONMENT:** STAGING / PRODUCTION (SAUCEDEMO.COM)

## PRECONDITIONS:
1. USER HAS VALID LOGGED-IN SESSION WITH PRODUCTS IN CART.
2. USER IS ON 'CHECKOUT: YOUR INFORMATION' FIELDS VIEW.

## STEPS TO REPRODUCE:
1. ENTER SPECIAL CHARACTERS '@@@' IN FIRST NAME BOX.
2. ENTER SPECIAL CHARACTERS '###' IN LAST NAME BOX.
3. PROVIDE VALID ZIP CODE VALUES AND CLICK CONTINUE.

## EXPECTED RESULT:
SYSTEM SHOULD RUN INPUT FORMAT VALIDATION FILTER ON NAME FIELDS AND REJECT SYMBOLS AND INVALID DATA CHARACTERS.

## ACTUAL RESULT:
SYSTEM IS ACCEPTING INVALID SYMBOL INPUTS AND ALLOWING THE CHECKOUT PROCESS WITHOUT ANY VALIDATION ERRORS.
