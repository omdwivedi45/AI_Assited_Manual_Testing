# BUG-003: ZIP CODE FIELD ACCEPTS ALPHABETICAL STRING AND LACKS LENGTH BOUNDARIES

- **SEVERITY:** MEDIUM
- **PRIORITY:** HIGH
- **MODULE:** CHECKOUT_INFORMATION
- **ENVIRONMENT:** STAGING / PRODUCTION (SAUCEDEMO.COM)

## PRECONDITIONS:
1. USER IS ACTIVE AND FILLING DATA ON 'CHECKOUT: YOUR INFORMATION' PAGE.

## STEPS TO REPRODUCE:
1. ENTER VALID CREDENTIALS FOR FIRST NAME AND LAST NAME fields.
2. IN THE POSTAL CODE INPUT BOX, TYPE THE ALPHABETICAL STRING 'ABCDE'.
3. CLICK CONTINUE AND VERIFY INPUT VALIDATION AND LENGTH LIMITS.

## EXPECTED RESULT:
THE POSTAL CODE DATA BLOCK MUST VALIDATE FORMAT MECHANICS AND STRICTLY RESTRICT ALPHABETICAL CHARACTERS OR INVALID MIN/MAX LENGTH BOUNDARIES.

## ACTUAL RESULT:
SYSTEM BYPASSED FORMAT VALIDATION; CHECKOUT PROCEEDS SUCCESSFULLY WITHOUT DETECTING ALPHABETICAL STRINGS OR LENGTH BOUNDARIES IN THE FIELD.
