# PROJECT REQUIREMENTS SPECIFICATION

| REQUIREMENT_ID | REQUIREMENT_DESCRIPTION |
| :--- | :--- |
| **REQ_001** | USER MUST BE ABLE TO LOG IN SUCCESSFULLY WITH VALID REGISTERED CREDENTIALS. |
| **REQ_002** | SYSTEM MUST BLOCK LOGIN WITH INVALID OR BLANK CREDENTIALS AND SHOW APPROPRIATE ERROR MESSAGES. |
| **REQ_003** | LOGOUT BUTTON MUST INSTANTLY TERMINATE THE ACTIVE SESSION AND REDIRECT USER TO THE LOGIN PAGE. |
| **REQ_004** | SYSTEM MUST REQUIRE VALID FIRST NAME, LAST NAME, AND ZIP CODE FOR SHIPPING AND CHECKOUT PROCESS. |
| **REQ_005** | CHECKOUT FIELDS MUST VALIDATE AGAINST SPECIAL CHARACTERS AND RESTRICT INVALID INPUT FORMATS. |
| **REQ_006** | SYSTEM MUST RESTRICT CHECKOUT PROCESS IF THE USER CART IS COMPLETELY EMPTY. |
| **REQ_007** | SYSTEM MUST PROVIDE FUNCTIONALITY TO ADD, REMOVE, AND SORT PRODUCTS ON THE INVENTORY PAGE. |
| **REQ_008** | SYSTEM MUST MAINTAIN THE CART COUNT AND RETAIN SELECTED ITEMS ACCURATELY DURING PAGE NAVIGATION. |
